# Risk register

| Risk | Current control | Remaining work |
| --- | --- | --- |
| Relevant-looking passage treated as advice | Public excerpts require explicit review and are labeled partial; no generation. | Measure retrieval misses and unsafe candidate use on approved material before enabling generation. |
| Unlicensed, stale or misattributed source | Operator records version, origin, permitted use, reviewer, and review deadline before publication. Expired material is filtered. | Obtain documented approvals, review conflicts by authority and jurisdiction, and operate a renewal schedule. |
| Interrupted indexing or stale vectors | PostgreSQL owns visibility and the active generation pointer. Unreferenced Chroma rows cannot establish approval. | Rehearse restore, measure cleanup cost, define retention and permanent purge. |
| Untrusted file or embedded directives | Only bounded local UTF-8 text is ingested; passages are not sent to a chat model; Laravel escapes catalog metadata. | Review isolated document conversion and prompt-injection handling before expanding parsers or enabling generation. |
| Sensitive material in staging, logs or chat history | Operator-only staging, ignored index and environment files, explicit approval of public excerpts, bounded server-side session transcripts with user deletion and no browser GPS persistence. | Establish formal session and backup retention, assess manually typed private data and stale historical source snapshots, and separate operator access before use outside the development laptop. |
| Emergency missed or misrouted | Bilingual deterministic patterns run first, with static references and no external calls. | Human-review instructions and hotline freshness; measure recall on urgent, negated, hypothetical and code-switched cases. Do not rely on chat as dispatch. |
| False location certainty or conflated hazard/vulnerability/risk | No active geographic adapter or classified Baguio dataset. Local and current requests abstain. | Validate CRS, positional error, boundaries, legend and classification before pilot; represent uncertainty and keep layer types separate. |
| Delayed or incomplete live data mistaken for an official warning | USGS is supplementary, with explicit scope, feed age checks, event times and no stale fallback after a failed refresh. Philippine current conditions abstain and point to official channels. | Verify agency machine interface, approved reuse and local coverage. Review emergency UX and escalation with local operators. |
| Provider billing, privacy or malicious search results | Search is off by default at the API; the browser opts into bounded automatic fallback by default and offers an off switch. Search is fixed-host, rate-limited per process, and sends no raw message or location. Results are link-only, domain-filtered and escaped; the server never opens them. | Verify authenticated Brave access and terms, review browser link/redirect risks, and set shared budgets and outbound allowlists before a public pilot. |
